# 🛒 ShoppyBara - Decentralized Online Shopping on the Internet Computer

Shoppybara is a modern, decentralized e-commerce platform powered by blockchain technology. Built using **Vite**, **React**, and **Motoko**, it leverages the **Internet Computer** to deliver a secure, censorship-resistant shopping experience.

> "Because capybaras deserve smooth shopping too."

## 🚀 Quick Start

### Prerequisites

Ensure you have the following installed:

- [Node.js](https://nodejs.org/) ≥ 16
- [DFX SDK](https://internetcomputer.org/docs/current/developer-docs/sdk-guide/quickstart) ≥ 0.14

### 📦 Installation

```bash
# Clone the starter
git clone http://github.com/OkToRen/Stackybara
cd stackybara

# Start local Internet Computer replica
dfx start --clean --background

# Install dependencies, deploy canisters, and generate types
npm run setup

# Start the development server
npm start
```

### ⭐ Development

```bash
# if opening the project after a restart
dfx start --clean --background

# create the canisters
dfx deploy

# run the frontend and backend
npm start
```
